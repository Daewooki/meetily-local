# Meetily Local 1.0.0

An independent Meetily Community fork for local Korean transcription and summarization, with optional Confluence and Jira publishing.

## Apple Silicon Mac

Target: M1 or later, macOS 14.2 or later; 16 GB memory and 5 GB free storage recommended, plus recording space. Windows and Intel Mac packages are not included.

Open the DMG, copy `Meetily Local.app` to Applications, and download approximately 3.3 GB of local models on first use. Current builds are ad-hoc signed and are not Apple-notarized. The installer contains no accounts, API tokens, meetings or model weights.

## Features

- On-device Whisper transcription and Qwen Korean meeting notes
- Evidence checks for the default Korean template; editable summaries and custom templates
- New Confluence pages under a page or folder, and Jira issue creation
- User-reviewed publication and encrypted Atlassian token storage with a Keychain key

Model preparation and Atlassian operations use the network. Transcription and summarization run offline after model setup. Meeting DB and recording files are not encrypted by the app. AI results need review.

See the repository's `LOCAL-MAC.md`, `docs/USAGE.md`, `NETWORK-POLICY.md`, `LOCAL-VALIDATION.md` and `CONTRIBUTING.md` for instructions, validation limits and contributions.
