# 한국어 회의록 품질 검증 — 1.0.0

2026-10-15, Apple Silicon Mac에서 기존 Qwen3.5-4B-Q4_K_M 모델을 사용해 확인했습니다. 회사 회의 자료는 사용하지 않았습니다. 이 기록은 소수 합성 사례의 기능 검증이며 기기별 성능, 일반적인 한국어 정확도 점수나 실회의 품질을 보장하지 않습니다.

## 바뀐 처리

- 한국어 선택 시 영어 중간 요약·재번역 없이 한국어로 처리합니다.
- 기본 한국어 회의록은 결정, 작업, 담당자, 기한, 원문 근거를 구조화해 추출하고, 원문과 비교하는 검수를 한 번 더 수행합니다.
- 앱이 제목·절·표·`미정` 표시를 만듭니다. 상단 요약도 같은 결정·할 일·미결 항목으로 구성해 별도 요약 문장이 상태나 기한을 추가하지 않게 했습니다.
- 모델은 원문 문장의 번호를 선택하고 앱이 해당 문장을 근거 칸에 넣습니다. 결정과 할 일의 근거 번호가 실제 전사문을 가리키는지 확인합니다. 담당자·기한 값도 해당 인용에 있어야 합니다. 검증 실패 시 한 번 다시 생성하고, 계속 실패하면 완료된 회의록으로 저장하지 않습니다. 이는 근거 번호·담당자·기한의 존재 검사이며 모든 문장의 의미적 정확성을 증명하지 않습니다.
- 긴 한국어 입력은 UTF-8 바이트를 보수적으로 계산해 겹치는 구간으로 나누고, 시간순 사실 메모를 합칩니다. 전체 메모가 크면 추가 압축합니다. 실제 모델 토큰 수와 출력 여유도 확인하며, 잘린 출력을 성공으로 처리하지 않습니다.
- 기본 템플릿을 수정한 경우에는 사용자 지시를 유지하는 Markdown 경로를 사용합니다. 위 구조 검사·추가 검수는 변경하지 않은 기본 한국어 템플릿에 적용됩니다.
- Qwen의 non-thinking 모드를 유지합니다. temperature 0.2, top-k 20, top-p 0.8, 반복/등장 패널티 없음. 이름과 기한을 여러 절에서 반복해야 하는 회의록에 맞춘 설정이며, 모든 작업에 최적인 값이라는 뜻은 아닙니다.

[Qwen 공식 모델 안내](https://huggingface.co/Qwen/Qwen3.5-4B)의 모드·샘플링 설명도 확인했습니다. 실제 선택은 이 앱의 로컬 비교 결과를 기준으로 했습니다. 모델 변경이나 추가 다운로드, 외부 AI 호출은 없습니다.

## 합성 사례에서 확인한 항목

| 사례 | 확인한 내용 |
| --- | --- |
| 시험 운영 | 한 명·일주일 결정, 민수·금요일, 지영·기한 미정, 전체 배포 일정 미정 |
| 일정 정정 | 출시 제안과 보류를 구분, 내부 데모 날짜만 확정, 시나리오 정리 기한 미정 |
| 숫자·기술 용어 | 현재 2.4초/목표 1.8초, 정정된 28건, Aurora·SDK v2.7.1, 수진·목요일, 원인은 가설 |
| 확정 업무 없음 | 미참석자를 담당자로 지정하지 않음, 일정 후보를 기한으로 확정하지 않음, 할 일 없음 |
| 인용된 악성 명령 | 테스트 문자열을 실제 업무로 실행하지 않음, 실제 할 일은 지영·금요일, 배포 미승인 |
| 앱의 시간 표시 | 실제 앱과 같은 시간 표시가 포함된 합성 전사문으로 생성·근거 선택 확인 |
| 후반 취소 | 4개 구간 처리 후 앞선 데모 일정·민수 업무 배정 취소 반영, 지영의 새 작업 유지 |

긴 사례는 반복 배경 문장을 넣어 구간 분리·병합과 후반 정정을 확인했습니다. 실제 1시간 회의의 정보 밀도, 여러 화자, 전사 오류를 재현한 사례가 아닙니다.

기존 방식에서는 미정인 기한을 `-`·`미지`로 표시하거나, 비어 있어야 할 할 일 표에 영어 안내 문장을 넣었습니다. 개선 결과에서는 해당 표 문제를 해소했습니다. 일부 본문에는 `기안` 같은 표현 오류나 논의 범위의 세부 누락이 남아 있으며, 정확한 인용을 보존하므로 음성 인식 오류가 원문에 있으면 그대로 나타날 수 있습니다. 게시 전 검토는 여전히 필요합니다.

## 시간과 재현

최종 버전에서 합성 사례 7개 모두 생성과 근거 검사를 통과했습니다. 각 결과는 사람이 읽어 위 항목도 확인했습니다. 기본 템플릿은 항목 추출과 추가 검수를 수행하므로 빠른 한 번 생성보다 시간이 더 걸릴 수 있습니다. 모델 로딩·배경 작업·입력 길이·재시도·샘플링에 따라 달라지며 속도 향상이나 통계적 품질 향상을 주장하는 벤치마크가 아닙니다. 상단 요약의 표시 방식과 근거 선택은 단위 테스트로도 검증합니다.

사례: `frontend/src-tauri/tests/fixtures/korean-summary-corpus.json`. 원시 실행 결과는 Git에 넣지 않은 `local-validation/qwen-quality/`에 보관합니다. 모델 평가 테스트는 기본 테스트에서 제외되며 다음과 같이 명시적으로 실행합니다.

```sh
MEETILY_LLAMA_HELPER="$PWD/target/release/llama-helper" \
MEETILY_EVAL_DATA_DIR="$HOME/Library/Application Support/ai.meetily.local" \
MEETILY_EVAL_OUTPUT="$PWD/local-validation/qwen-quality/reproduced" \
MACOSX_DEPLOYMENT_TARGET=14.2 CARGO_BUILD_JOBS=8 \
cargo test --locked --release -p meetily --lib evaluate_korean_summary_corpus -- --ignored --nocapture
```

일반 회귀 테스트는 `cargo test --locked --release -p meetily --lib summary::`입니다. 외부 Ollama HTTP 연결을 전제로 한 원본 테스트 3개는 이 로컬 전용 빌드에서 제외했고, 외부 호출 차단 테스트는 계속 실행합니다. 예전 테스트 전체 실행 시 발견한 실패/대기는 이 정책 차이에서 발생했으며, 외부 연결을 다시 허용해 통과시키지 않았습니다.
